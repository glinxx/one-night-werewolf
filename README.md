# 一夜狼 · 语音主持

一个**单文件**的「一夜狼人」桌游语音主持工具。打开即用，无需安装任何依赖，由浏览器自带语音合成（Web Speech API）自动用中文播报夜晚各角色的行动指令，并配合倒计时带领全场完成夜晚流程。

> 本文件由原始散落文件 `9f4630ca9f5840d89757fe4e9c2815c4.html` 改名整理而来。

## 快速开始

1. 用浏览器（推荐 Chrome / Edge）打开 `一夜狼-语音主持.html`；
2. 选择角色及数量（可直接使用内置预设方案）；
3. 设置每位角色夜晚操作时间（默认 15 秒）；
4. 实体发牌后点击「开始游戏」；
5. 夜晚阶段跟随语音提示：全员闭眼 → 各角色依次睁眼行动 → 自动倒计时；
6. 天亮后进入自由讨论与投票环节。

## 功能特性

- 🎙️ **中文语音主持**：自动选用系统中文语音，播报每个角色的「睁眼 / 行动 / 闭眼」指令
- ⏱️ **自动倒计时**：语音播报结束后自动开始计时，最后 10 秒语音倒数，结束自动进入下一角色
- 🃏 **17 种角色**：狼人阵营、好人阵营、独立阵营全覆盖，支持自由增减数量
- ⚡ **三套预设方案**：基础 6 人局 / 8 人局 / 进阶 9 人局，一键配置
- 🔁 **灵活控制**：暂停 / 继续、跳过播报、重新播报、历史记录回看
- 🌙 **夜间主题 UI**：星空闪烁、月亮背景，仪式感拉满

## 角色一览

| 阵营 | 角色 |
| --- | --- |
| 🐺 狼人阵营 | 狼人、头狼、狼先知、爪牙 |
| 🛡️ 好人阵营 | 守夜人（需成对）、预言家、学徒预言家、强盗、女巫、捣蛋鬼、酒鬼、失眠者、揭示者、村民、猎人 |
| ⚰️ 独立阵营 | 皮匠 |
| 👻 随所看 | 化身幽灵（复制他人身份，新手可不选） |

**游戏规则**：场上角色牌总数 = 玩家人数 + 3，其中 3 张作为中央底牌。

**夜晚行动顺序**（按选定角色自动生成）：化身幽灵 → 狼人 → 头狼 → 狼先知 → 爪牙 → 守夜人 → 预言家 → 学徒预言家 → 强盗 → 女巫 → 捣蛋鬼 → 酒鬼 → 失眠者 → 揭示者。

## 技术说明

- **形态**：纯 HTML / CSS / JavaScript 单文件应用，无任何外部依赖，无需构建步骤
- **语音引擎**：浏览器 `speechSynthesis` + `SpeechSynthesisUtterance`，自动匹配中文语音（`zh` / `cmn`）
- **平台要求**：系统需装有中文语音包（Windows 10/11 自带，macOS、主流移动端浏览器亦支持）
- **注意事项**：浏览器存在自动播放限制，语音须在用户点击「开始」后触发，属正常现象

## 使用提示

- 语音播报前请调高设备音量，并确保系统语音为中文；
- 若个别浏览器无中文语音，可在系统「语音设置」中添加中文语音包后刷新页面；
- 建议将本文件备份或发送到手机，局域网内也可直接通过浏览器打开游玩。
